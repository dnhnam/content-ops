# Brief: Dùng Claude Code cloud session để chạy kho nội dung, không cần biết code

> Brief mẫu. Phần "Trải nghiệm thật" mới chỉ có những gì đã xảy ra đến hôm nay (18/10/2026). Điền các chỗ [NAM: ...] trước khi giao Claude viết, nếu không bài sẽ đầy chỗ trống.

## Người đọc là ai, họ đang gặp chuyện gì

Marketer và chủ doanh nghiệp nhỏ đã dùng Claude để viết bài, nhưng mỗi lần lại phải dán lại hướng dẫn giọng văn, bài cũ, brief vào khung chat. Họ nghe tới Claude Code nhưng nghĩ đó là việc của lập trình viên.

## Bài này giúp họ làm được gì

Dựng một repo GitHub chỉ chứa file Markdown (brief, style guide, bài nháp) và giao Claude viết bài trên cloud, review trên điện thoại như review code.

## Trải nghiệm thật (bắt buộc, 3-5 gạch đầu dòng)

- Tôi nhận được coupon dùng cloud session của Claude. Mở ra thì gặp ngay dòng yêu cầu phải có GitHub repository mới bắt đầu được, và câu hỏi đầu tiên của tôi là: cái này dùng để làm gì?
- Ngày 18/10/2026 tôi kết nối GitHub xong, rồi dựng repo `content-ops` gồm `CLAUDE.md` (hướng dẫn cố định), `STYLE.md` (giọng văn rút từ style guide của blog), thư mục `briefs/`, `drafts/`, `social/`, `published/`.
- `STYLE.md` lấy từ style guide giọng văn tôi đã làm hồi tháng 9/2026, nên Claude không phải đoán giọng mỗi lần.

- [NAM: so sánh với cách cũ (dán prompt vào chat): mỗi bài tốn bao nhiêu phút chuẩn bị trước đây và bây giờ]

## Ý chính muốn có

- Cloud session không chỉ cho code: repo có thể chỉ chứa Markdown.
- `CLAUDE.md` và `STYLE.md` thay cho việc dán đi dán lại prompt.
- Review bài như review code: xem diff, comment từng dòng, Claude sửa.
- Giới hạn: mạng bị chặn mặc định, chưa dùng được các connector như Canva, Google Drive trong cloud session; bước đăng bài và tạo ảnh vẫn chạy ở máy.

- Giá gói và chi tiết coupon.
